1 Year Computer Science Roadmap

From Absolute Beginner to Internship-Ready

Overview

  • Total Duration: 12 Months
  • Commitment: 8–12 hours/week (approx. 2 hours/day)

Primary Goals

  • Understand computers deeply (Hardware, OS, Networking).
  • Build strong foundations in Programming & Problem Solving.
  • Learn essential CS concepts & Project Management.
  • Become Internship-Ready by Month 10–12.

Month 1: Understanding Computers

Build the foundation before you touch code. Understand the machine.

Key Topics

Hardware Basics (CPU, RAM) Binary/Hex Systems OS Overview (Win/Linux) Files & Processes

Exercises

  • Open your PC/Laptop (or look up teardowns) to identify components.
  • Practice converting Decimal to Binary manually.
  • Install Ubuntu in VirtualBox and try basic commands.

Mini Project

Create a visual diagram explaining how a computer works internally.

Month 2: Computer Literacy & Internet

Mastering the tools, networking basics, and staying safe online.

Key Topics

  • Internet: DNS, IP Addresses, Routers, Browsers.
  • Security: Phishing, Encryption, Password Management.
  • Cloud: Drive, Dropbox, Email Etiquette.

Resources

"The Internet Book" by Douglas Comer, Khan Academy Internet 101.

Mini Project

Create a "Beginner’s Guide to Internet Safety" (PDF or simple Google Site).

Month 3: Introduction to Python

Your first steps into logic and coding.

Key Topics

  • Compilers vs Interpreters.
  • Variables, Data Types, and Operators.
  • Control Flow: Conditionals (`if/else`) and Loops (`for/while`).

Exercises

  • Build a calculator script.
  • Create a temperature converter.

Mini Project

Build a Command Line Personal Expense Tracker.

Month 4: Python Foundations

Data Structures & Problem Solving logic.

Key Topics

Lists & Tuples Dictionaries & Sets Functions Error Handling

Algorithmic Thinking

  • Basic searching and sorting logic.
  • Practice on HackerRank (Beginner level).

Mini Project

Student Report Card System (Add, Search, Update records).

Month 5: Core CS Concepts

Going deeper: How software interacts with hardware.

Key Topics

  • Memory: Stack vs Heap.
  • OS Internals: Processes, Threads, Scheduling.
  • Data Structures: Linked Lists, Stacks, Queues.
  • Big-O: Basic complexity analysis.

Resources

Neso Academy (YouTube), "Computer Science Illuminated".

Mini Project

Implement a Stack and Queue manually in Python.

Month 6: Databases & SQL

Handling data persistence and organization.

Key Topics

  • Relational Databases (Why they exist).
  • SQL Commands: SELECT, INSERT, UPDATE, DELETE.
  • Joins, Keys, and Normalization.
  • SQLite / MySQL basics.

Mini Project

Library Management System (Python script connected to SQLite).

Month 7: Web Development Basics

Understanding the Client-Server model and frontend.

Key Topics

HTML5 Structure CSS Styling Basic JavaScript HTTP Request/Response

Exercises

  • Build simple static pages with forms.
  • Read MDN Web Docs.

Mini Project

Personal Portfolio Website (Host it on GitHub Pages).

Month 8: Deepening Knowledge

OOP, APIs, and Version Control.

Key Topics

  • OOP: Classes, Objects, Inheritance in Python.
  • APIs: Fetching data (JSON), REST basics.
  • Git/GitHub: Commits, Push, Pull.

Mini Project

Weather App (Fetch data from a public API, display in CLI or GUI).

Month 9: Specialization Preview

Explore a track before committing to a career path.

Choose One Path to Explore

  • Web Development: Backend frameworks (Django/Flask).
  • Data Analytics: Pandas, Matplotlib.
  • Cybersecurity: Network scanning, basic ethical hacking.
  • App Dev: Basics of Android/Flutter.

Mini Project

Build one small project in your chosen field (e.g., A simple Blog or Data Visualization).

Month 10: The Major Project

Spend 4-6 weeks building something substantial.

Project Ideas

  • Student Portal Web App.
  • Inventory Management System.
  • Basic E-Commerce Mockup.

Focus Areas

  • Using Git branching.
  • Writing clean documentation (README.md).
  • Debugging without tutorials.

Month 11: Professional Skills

Preparing for the real world.

Key Topics

  • Resume: Tailor it to your skills.
  • LinkedIn: Network with professionals.
  • Cloud: Intro to AWS/Render (Deployment).
  • Agile: Basics of SDLC (Software Dev Lifecycle).

Mini Project

Deploy your Major Project (from Month 10) to the cloud (Heroku/Render/AWS).

Month 12: Job & Internship Prep

Application strategy and interviews.

Action Plan

  • Apply on Internshala, LinkedIn, Naukri, AngelList.
  • Look for local startups (Gomti Nagar/Hazratganj hubs).
  • Interview Prep: Review Python, DSA basics, SQL.

Final Output

A polished PDF Portfolio + A clean GitHub profile.

Weekly Study Routine

Consistency beats intensity. Aim for 8-12 hours/week.

Day Activity Time
Day 1 Learn Theory (Book/Video) 1-2 hrs
Day 2 Coding Practice 1 hr
Day 3 Theory + Notes 1 hr
Day 4 Project Building 1-2 hrs
Day 5 Revision / Extra 1 hr

Tips for Success

Staying Motivated

  • Keep a learning journal.
  • "Just 1 hour today" is better than 0.
  • Celebrate small wins (fixing a bug is a win!).

Standing Out (Local Context)

  • Attend events at local colleges (AMITY, BBDU, IIIT Lucknow).
  • Participate in Hackathons (Devfolio, HackerEarth).
  • Contribute to Open Source.

End of Year Outcome

  • ✅ Understand computers from the ground up.
  • ✅ Write clean, functional Python code.
  • ✅ Have 5–8 projects in your portfolio.
  • ✅ Understand Databases, Web Basics, and APIs.
  • ✅ Ready to apply for Internships.

Keep going. You got this!
